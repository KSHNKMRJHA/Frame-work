# Streamlit features that arrived well after 1.38:
#
#   1.40.0  st.pills, st.segmented_control            (Encyclopedia, Settings)
#   1.47.0  theme.linkUnderline,
#            theme.dataframeHeaderBackgroundColor       (.streamlit/config.toml)
#   1.48.0  width= on button / link_button /
#            form_submit_button
#   1.49.0  width= on pyplot / image / dataframe,
#            st.dialog(width=)
#   1.51.0  [theme.sidebar] and [theme.light] sections,
#            st.plotly_chart(width=)
#   1.55.0  theme.metricValueFontWeight               (.streamlit/config.toml)
#
# `build_scripts/check_streamlit_floor.py` verifies this at runtime: it checks
# that the installed Streamlit satisfies the bound and that every theme key in
# config.toml is a key that Streamlit actually recognises (unknown keys are
# ignored silently, which would produce a quietly wrong-looking app).
